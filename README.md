# SP7 음색 슬롯 점유 현황

SP7 신기체·구기체 두 대의 음색 저장 슬롯(각 64칸, 그룹 A~D × 16칸)을 멤버들이 직접 점유하고 현황을 보는 홈페이지입니다.

- 홈페이지: GitHub Pages (무료)
- 점유 데이터: 구글 시트 + Apps Script (무료)
- 빈 칸을 여러 개 골라 **한 번에 점유**합니다. 그룹마다 "빈 칸 모두 선택" 버튼이 있습니다.
- 함께 점유한 칸들은 한 묶음으로 기억되어, 수정·취소할 때 묶음 전체를 한 번에 처리할 수 있습니다.
- 점유할 때 정한 **4자리 PIN**으로 수정·취소합니다. 기간이 지난 칸은 누구나 "비우기"로 정리할 수 있습니다.

```
index.html            ← 홈페이지 (GitHub에 올리는 파일)
apps-script/Code.gs   ← 구글 시트에 붙여 넣을 코드
```

---

## 1. 구글 시트 만들기

1. [sheets.new](https://sheets.new) 에서 새 스프레드시트를 만들고 이름을 `SP7 슬롯 점유`처럼 정합니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본으로 있는 `Code.gs` 내용을 모두 지우고, 이 저장소의 `apps-script/Code.gs` 내용을 통째로 붙여 넣은 뒤 저장(💾)합니다.
4. 위쪽 함수 선택 칸에서 `setup` 을 고르고 **실행**을 누릅니다.
   - "승인 필요" 창이 뜨면 본인 계정을 고르고 **고급 → (안전하지 않음)으로 이동 → 허용**을 누릅니다. 본인이 만든 스크립트라 뜨는 일반적인 경고입니다.
   - 시트에 `slots` 탭이 생기면 성공입니다.

### (선택) 관리자 PIN
Apps Script 왼쪽 **⚙ 프로젝트 설정 → 스크립트 속성 → 속성 추가**에서
`ADMIN_PIN` = `원하는 숫자 4자리` 를 넣으면, 그 PIN으로 모든 점유를 수정·취소할 수 있습니다. PIN을 잊은 멤버를 도와줄 때 씁니다.

## 2. 웹 앱으로 배포하기

1. Apps Script 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형 선택(⚙)에서 **웹 앱**을 고릅니다.
3. 설정:
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누르고, 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> 이전 버전 `Code.gs`를 이미 배포했다면 새 코드로 교체한 뒤 아래처럼 새 버전으로 다시 배포하세요. 기존 시트에는 `batch` 열이 자동으로 추가됩니다.
>
> 나중에 `Code.gs`를 고쳤다면 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다. URL은 그대로 유지됩니다.

## 3. 홈페이지에 주소 넣기

`index.html`을 열어 아래 줄을 찾아 따옴표 안에 2단계의 URL을 붙여 넣습니다.

```js
const API_URL = '';
```
↓
```js
const API_URL = 'https://script.google.com/macros/s/여기에_복사한_주소/exec';
```

## 4. GitHub Pages로 공개하기

1. GitHub에서 **New repository**를 만듭니다 (예: `sp7-slots`, Public).
2. **Add file → Upload files**로 `index.html`(과 `apps-script` 폴더, `README.md`)를 올리고 **Commit changes**.
3. 저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 정하고 **Save**.
4. 1~2분 뒤 `https://아이디.github.io/sp7-slots/` 주소로 접속됩니다. 이 주소를 멤버들에게 공유하세요.

## 운영 메모

- **시트에서 직접 고쳐도 됩니다.** 날짜는 `2026-12-24`처럼 `YYYY-MM-DD` 형식을 지켜 주세요. `pinHash` 열은 건드리지 마세요(빈칸이면 관리자 PIN으로만 수정·취소 가능). `batch` 열이 같은 줄들이 함께 점유한 묶음입니다.
- **PIN은 시트에 원문으로 저장되지 않습니다.** 해시값만 저장되므로 시트를 봐도 PIN을 알 수 없습니다.
- 현황은 30초마다, 그리고 탭으로 다시 돌아올 때 자동으로 새로 불러옵니다.
- 같은 칸을 두 사람이 동시에 점유하면 먼저 도착한 쪽만 저장되고 나머지는 "이미 점유된 칸" 안내를 받습니다.
- 공용 비밀번호는 없으므로 주소를 아는 사람은 누구나 빈 칸을 점유할 수 있습니다. 주소는 멤버끼리만 공유하세요.
